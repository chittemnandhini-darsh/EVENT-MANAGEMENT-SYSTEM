# EVENT-MANAGEMENT-SYSTEM

## 📌 Project Description

The **Event Management System** is a web-based application developed using **HTML, CSS, and JavaScript**.

The system allows users to view upcoming events, search for events, register for an event, and receive a registration confirmation message.

This project provides a simple and user-friendly interface for managing and participating in events.

---

## 🎯 Objectives

* To create an easy-to-use event management website.
* To display upcoming events.
* To allow users to search for events.
* To provide online event registration.
* To validate user registration details.
* To display registration success messages.
* To create a responsive website for different screen sizes.

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and form handling
* **VS Code** – Development environment
* **Live Server** – Running the website locally

---

## 📂 Project Structure

```text
EventManagement/
│
├── index.html
├── style.css
└── script.js
```

### Files Description

**index.html**

* Creates the main structure of the website.
* Contains Home, Events, About, Registration, and Contact sections.

**style.css**

* Provides colors, layouts, spacing, buttons, cards, forms, and responsive design.

**script.js**

* Handles event registration
